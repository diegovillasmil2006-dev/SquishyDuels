# Squishy Duels UI Icon Refresh v1

A non-destructive icon refresh based on the existing Squishy Duels sticker-sheet style and the supplied UI screenshots. Each PNG is an individual icon on a transparent background. Keep UI labels, quantities, prices, and multiplier text as separate Roblox UI text so they remain crisp and localizable.

## Files

- `coin_currency.png` — HUD coin/currency symbol
- `settings.png` — settings button icon
- `double_coins.png` — 2x Coins booster art
- `double_grip.png` — 2x Grip booster art
- `lucky_boxes.png` — Lucky Boxes booster art
- `fast_open.png` — Fast Open booster art
- `coin_pack_1000.png` — first coin shop offer (small coin stack)
- `coin_pack_3300.png` — second coin shop offer (coin pouch)
- `coin_pack_9600.png` — third coin shop offer (treasure chest)
- `coin_pack_32500.png` — fourth coin shop offer (large coin mound)

These are art assets only; no HUD layout, scripts, or live Roblox UI were changed. Upload each PNG in Roblox and assign its resulting asset id to the matching ImageLabel/ImageButton.
