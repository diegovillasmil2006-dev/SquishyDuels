## Fixed
(one line each: what was wrong, what changed, how it was checked, snapshot)
1. **Stairs in matches pulled you back / throws from stairs fizzled.** The hidden ramp under every stair is a wedge,
   but the server's "are you inside a wall" check and the throw / ultimate "is there room" check treated it as a full
   box, so anyone on a stair in a duel or match counted as inside a wall: the movement guard snapped them back to the
   stair's foot every 0.2 s, every throw from a stair fizzled and the ultimate said "no room". Fix: HitMath.pointInShape
   knows a Wedge; CombatService.overlapsGeometry (throws, ultimate room) counts a wedge only when the point is really
   inside it; the guard uses the wedge shape. Files: Logic/HitMath, Services/CombatService, Services/AbilityService
   (+ HitMath_Test). Checked: before the fix a real 1v1 climb on Pencil Case was yanked back 8.8 studs and never reached
   the top; after it 5/5 climbs up and down reached (1.6 s each, no snaps) and a throw from mid-ramp flew (impact
   "geometry", not "fizzle"). Tests 3,880/3,880. Snapshot c7765d5.
2. **The pen's SELL button (chosen squishies) never sold anything.** The client checks every remote's arguments
   before sending, and the list of pen item ids ("itemIds") had no check, so SellItems was refused on the client every
   time ("argument 1 (ids) is not a valid itemIds; nothing sent"); SELL ALL and BUY BACK were fine. Fix: the missing
   check in Client/Controllers/NetController + 2 tests (one checks every argument type of every remote has a check).
   Checked: in a test game SellItems was refused before and sells after.
3. **Log noise: "Unknown image key: img.vote.board.<map>" on every vote.** The vote board asked for an optional
   board picture through the warning lookup. Fix: AssetTable.hasImage (quiet) for the optional pictures
   (Client/UI/MatchVoteBoard). Checked: no warning in the next vote. Snapshot 0bd72b7 (with 2).
4. **The 1v1 practice bot never came round the middle deck.** On the sky maps it walked in a straight line to each
   random spot of its half, ran into the middle deck and hugged it for the whole duel (a 150 s duel vs the bot: 16
   throws, 0 hits, all into the deck). Fix: the bot's walk follows a PathfindingService path when one exists
   (Services/BotService: walkTo / followPath, the vault's follower cut down; a failed path keeps the straight walk).
   Checked: a 1v1 vs the bot on Piano Keys with the new walk: no errors, the bot crossed the map, got a clear line
   and hit me within seconds once I stepped out from behind my spawn wall (before: 150 s, 0 hits). The Free for All /
   Team bots have their own walking code (MatchBotService) and are unchanged. Tests 3,882/3,882. Snapshot 383ec88.
5. **Log noise for the new Rare tier.** Every Rare squishy plate (and its reveal stage) warned "Unknown image key:
   img.fx.radial.plateRare / stageRare": the Rare tier (2026-11-01) had no picture slots like the other tiers. Fix:
   the two placeholder slots in Shared/AssetTable (no picture, the drawn glow is used, like every tier).
